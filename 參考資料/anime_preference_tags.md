# Anime Preference Tags

## 類型標籤

| 類型 | 說明 | 代表作品 |
|---|---|---|
| 戰鬥 | 角色有明顯戰鬥、能力、對抗 | 鬼滅之刃、咒術迴戰 |
| 戀愛 | 以感情發展為主 | 堀與宮村、青春豬頭少年 |
| 校園 | 場景以學校生活為主 | 月刊少女野崎同學、輝夜姬想讓人告白 |
| 奇幻 | 有魔法、異世界、非現實設定 | 葬送的芙莉蓮、無職轉生 |
| 懸疑 | 劇情有謎團、推理、反轉 | 進擊的巨人、死亡筆記 |
| 日常 | 生活化、輕鬆、節奏穩定 | 搖曳露營、孤獨搖滾 |
| 運動 | 以比賽、訓練、團隊成長為主 | 排球少年、藍色監獄 |

## 情緒標籤

| 情緒 | 說明 |
|---|---|
| 熱血 | 戰鬥、努力、成長 |
| 治癒 | 輕鬆、放鬆、壓力低 |
| 感動 | 友情、親情、人生議題 |
| 燒腦 | 推理、反轉、伏筆 |
| 搞笑 | 喜劇、誇張演出 |
| 沉重 | 黑暗、死亡、心理壓力 |

## 排雷標籤

| 使用者不想看 | 避免推薦 |
|---|---|
| 不要血腥 | 避免獵奇、重口味戰鬥番 |
| 不要後宮 | 避免多女角戀愛競爭設定 |
| 不要太虐 | 避免主要角色大量死亡或悲劇結局 |
| 不要太長 | 避免超過 50 集以上作品 |
| 不要慢熱 | 避免前期鋪陳太長作品 |
