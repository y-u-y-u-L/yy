# Japanese Anime Recommendation Skill

## Purpose

這個 Skill 用於根據使用者的觀看需求與喜好，推薦符合條件的日本動漫作品。  
推薦範圍僅限日本動漫，並需要說明推薦原因、適合對象、可能不適合的地方，以及替代選項。

## Core Principles

1. 僅推薦日本動漫作品。
2. 先分析使用者需求，再進行推薦。
3. 推薦時不能只列作品名稱，必須說明推薦理由。
4. 必須考慮使用者不想看的內容，例如血腥、後宮、虐心、集數太長等。
5. 推薦結果應該包含不同選擇，而不是只推薦同一類型作品。
6. 若使用者需求不清楚，應根據常見觀看偏好進行合理判斷。

## User Preference Analysis

當使用者提出需求時，先分析以下條件：

- 喜歡的類型：戀愛、校園、戰鬥、奇幻、懸疑、科幻、運動、日常、搞笑等。
- 觀看目的：放鬆、想哭、想熱血、想燒腦、想看劇情反轉。
- 劇情節奏：快節奏、中等、慢熱。
- 集數需求：短篇、中篇、長篇。
- 排雷條件：不要血腥、不要後宮、不要太沉重、不要爛尾。
- 相似作品：使用者是否有提到喜歡的作品。

## Anime Tag Mapping

將使用者需求轉換成推薦標籤：

| 使用者需求 | 推薦標籤 |
|---|---|
| 想看輕鬆的 | 日常、搞笑、治癒 |
| 想看感動的 | 催淚、成長、人生 |
| 想看刺激的 | 戰鬥、冒險、奇幻 |
| 想看燒腦的 | 懸疑、心理、推理 |
| 想看戀愛的 | 校園、青春、戀愛 |
| 不想看太長 | 短篇、12集、24集內 |
| 不想看血腥 | 排除獵奇、重口味、過度暴力 |

## Standard Workflow

### Step 1: 收集使用者需求

先讀取使用者輸入的條件，例如：

> 我想看輕鬆一點的日本動漫，不要太長，也不要太沉重。

### Step 2: 分析偏好

將需求拆解成條件：

- 類型：日常、搞笑、治癒
- 節奏：輕鬆
- 集數：短篇
- 排雷：不要沉重

### Step 3: 篩選動漫

根據條件篩選符合的日本動漫作品。

### Step 4: 排序推薦

推薦排序依照以下標準：

1. 類型符合度
2. 情緒符合度
3. 集數符合度
4. 排雷符合度
5. 作品評價與知名度

### Step 5: 輸出推薦結果

每次推薦至少包含：

- 動漫名稱
- 推薦理由
- 適合對象
- 可能不適合的地方
- 替代推薦
